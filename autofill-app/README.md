# OneTap (working title): AI sign-up & login autofill: project kit

This folder doesn't belong to the slot game. It's a self-contained starter kit for a separate app. Move it
into its own new repository before building.

| File | What it is |
|---|---|
| `MASTER_PROMPT.md` | The full, detailed build prompt. Paste it into Claude Code in the new repo |
| `WHAT_ELSE_NEEDS_TO_BE_DONE.md` | Everything beyond code: legal, security audit, stores, money, open decisions |
| `.claude/agents/*.md` | 14 specialist Claude Code agents, one per task area. `product-lead` orchestrates |

Quick start: create a new repo, copy this folder's contents to its root (so `.claude/agents/` sits at the
root), open Claude Code there, and say: *"Use the product-lead agent to read MASTER_PROMPT.md and
start Milestone 1."*
